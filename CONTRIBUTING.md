# Contributing to lunar-intelligence

## Code of Conduct

This project is committed to providing a welcoming and inclusive environment. Please be respectful and constructive in all interactions.

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion:

1. Check existing issues to avoid duplicates
2. Provide a clear, concise description
3. Include steps to reproduce (if applicable)
4. Mention your environment (Python version, OS, dependencies)

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/description`
3. Make your changes
4. Ensure code is clean and documented
5. Submit a pull request with a clear description
